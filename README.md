# 📚 লাইব্রেরী ম্যানেজমেন্ট সিস্টেম (Library Management System)

একটি পূর্ণ-বৈশিষ্ট্যযুক্ত লাইব্রেরী ম্যানেজমেন্ট সিস্টেম যা ব্যবহারকারী এবং প্রশাসক উভয়ের জন্য ডিজাইন করা হয়েছে।

---

## 🎯 প্রজেক্ট ওভারভিউ

এটি একটি **Tkinter-ভিত্তিক ডেস্কটপ অ্যাপ্লিকেশন** যা বইয়ের তালিকা পরিচালনা, ব্যবহারকারী নিবন্ধন, লগইন, বই ধার নেওয়া এবং ফেরত ট্র্যাকিং প্রদান করে।

**প্রযুক্তি স্ট্যাক:**
- 🐍 Python 3.7+
- 🗄️ SQLite3 Database
- 📝 Object-Oriented Programming (OOP)

## 🗄️ ডাটাবেস স্কিমা

### টেবিল গঠন

#### 1️⃣ **users** টেবিল
ব্যবহারকারীর তথ্য সংরক্ষণ করে।

```
user_id (INTEGER, PRIMARY KEY)
username (TEXT, UNIQUE)
email (TEXT, UNIQUE)
password (TEXT, হ্যাশ করা)
role (TEXT: 'user' বা 'admin')
created_at (TIMESTAMP)
is_active (BOOLEAN)
```

#### 2️⃣ **books** টেবিল
বইয়ের তথ্য সংরক্ষণ করে।

```
book_id (INTEGER, PRIMARY KEY)
title (TEXT)
author (TEXT)
category (TEXT)
price (REAL)
quantity (INTEGER)
isbn (TEXT, UNIQUE)
published_year (INTEGER)
description (TEXT)
created_at (TIMESTAMP)
updated_at (TIMESTAMP)
```

### 3️⃣ **loans** টেবিল
ব্যবহারকারীর ধার নেওয়া বইয়ের রেকর্ড সংরক্ষণ করে।

```
loan_id (INTEGER, PRIMARY KEY)
user_id (INTEGER, FOREIGN KEY)
book_id (INTEGER, FOREIGN KEY)
quantity (INTEGER)
issued_at (TIMESTAMP)
due_date (TIMESTAMP)
returned_at (TIMESTAMP)
status (TEXT)
```

#### 4️⃣ **wishlist** টেবিল
ব্যবহারকারীর পছন্দের বইয়ের তালিকা।

```
wishlist_id (INTEGER, PRIMARY KEY)
user_id (INTEGER, FOREIGN KEY)
book_id (INTEGER, FOREIGN KEY)
added_at (TIMESTAMP)
```

#### 5️⃣ **transactions** টেবিল
সব কেনাকাটার লেনদেন রেকর্ড করে।

```
transaction_id (INTEGER, PRIMARY KEY)
user_id (INTEGER, FOREIGN KEY)
book_id (INTEGER, FOREIGN KEY)
quantity (INTEGER)
price (REAL)
transaction_date (TIMESTAMP)
```

### সমস্যা: প্রোগ্রাম চালু হচ্ছে না

**সমাধান:**
```bash

```

### সমস্যা: "ModuleNotFoundError: No module named 'sqlite3'"

**সমাধান:**
SQLite3 সাধারণত Python এর সাথে অন্তর্ভুক্ত থাকে। যদি সমস্যা হয়:
```bash
# Ubuntu/Debian
sudo apt-get install python3-sqlite3

# MacOS
brew install python3
```
